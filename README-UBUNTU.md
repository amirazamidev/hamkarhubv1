# راهنمای کامل راه‌اندازی همکار هاب روی اوبونتو (Ubuntu Server) و میکروتیک

## ۱. نصب خودکار روی سرور اوبونتو فقط با یک کامند (بدون نیاز به انتقال فایل):

### روش الف: نصب مستقیم و سریع با یک کامند (Web One-Liner):
کافیست در ترمینال سرور اوبونتو دستور زیر را اجرا کنید (اسکریپت تمام فایل‌ها و وابستگی‌ها را خودش دانلود، کامپایل و به عنوان سرویس دائمی فعال می‌کند):
```bash
curl -sSL https://ais-pre-tiup3s7akyiwcghfvar7uk-751417033854.europe-west2.run.app/install.sh | bash
```

### روش ب: نصب مستقیم از طریق گیت‌هاب (GitHub One-Liner):
اگر پروژه را در مخزن گیت‌هاب خود قرار داده‌اید:
```bash
bash -c "$(curl -fsSL https://raw.githubusercontent.com/amirazamidev/hamkarhub/main/install-quick.sh)"
```
یا با کلون مستقیم ریپو:
```bash
git clone https://github.com/amirazamidev/hamkarhub.git && cd hamkarhub && sudo ./install-ubuntu.sh
```

این اسکریپت‌ها به صورت کاملاً خودکار:
- بسته‌های `curl`, `git`, `unzip`, `ufw` را نصب می‌کنند.
- Node.js نسخه 20 LTS را نصب یا به‌روز می‌کنند.
- برنامه را آماده، پکیج‌های npm را نصب و فرانت‌اند را بیلد می‌نمایند.
- پورت 3000 را در فایروال UFW باز می‌کنند.
- سرویس `hamkarhub.service` را در `systemd` ثبت و فعال می‌کنند تا سرور پس از ریبوت هم همیشه روشن بماند.

### 💡 نکته مهم برای سرورهای با پردازنده قدیمی (مانند AMD Phenom و Core 2):
اگر سرور شما دارای پردازنده‌های قدیمی مانند `AMD Phenom 9550 Quad-Core` باشد، این پردازنده‌ها فاقد دستورالعمل‌های جدید SSE4.2 و AVX هستند و اجرای دستور `vite build` در آن‌ها باعث خطای `Illegal instruction (core dumped)` می‌شود.
**راه‌حل در این مخزن پیاده‌سازی شده است:**
۱. فایل‌های بیلد نهایی (`dist/` و `server.js`) از قبل در پروژه قرار داده شده‌اند.
۲. اسکریپت نصب به طور خودکار نوع پردازنده را از `/proc/cpuinfo` تشخیص می‌دهد و در پردازنده‌های قدیمی، به جای کامپایل مجدد، از بیلد آماده استفاده کرده و سرور را مستقیماً با `node server.js` اجرا می‌کند.
۳. دستور به‌روزرسانی سریع برای حل خطا:
```bash
cd /opt/hamkarhub && git pull && sudo ./install-ubuntu.sh
```

## ۲. حل قطعی ارور «challenge response, try again, enable javascript» میکروتیک:
این خطا زمانی رخ می‌دهد که در میکروتیک متد ورود فقط روی `http-chap` باشد. برای رفع آن، دستور زیر را در ترمینال میکروتیک (Winbox -> New Terminal) اجرا کنید:
```routeros
/ip hotspot profile set [find] login-by=http-pap,http-chap,trial,cookie
```
با این دستور، متد **HTTP-PAP** فعال شده و روتر میکروتیک پسورد ورودی را از صفحه وب می‌پذیرد و ارور چلنج برطرف می‌شود.

## ۳. دستور باز کردن دسترسی چت برای کاربران قبل از لاگین (Walled Garden):
```routeros
/ip hotspot walled-garden ip
add action=accept comment="HamkarHub Local Server" dst-address=192.168.88.254 dst-port=3000
```
(آدرس `192.168.88.254` را با آی‌پی سرور اوبونتو خود جایگزین فرمایید).
